# PRD: SSS pptx2pdf

## 背景

講義資料の PowerPoint デッキを配布用の PDF にするとき、次の 2 つの問題があった。

- PowerPoint の「PDF として保存」は、書式の切れ目（run の境界）にある半角スペースを文字として書かず、位置情報だけにする。学生が PDF からコマンド行をコピーすると、`git add` の空白が消える。
- 印刷経路（Microsoft Print to PDF）なら空白は残るが、Microsoft Print to PDF は V4 型のクラスドライバーで、登録した用紙を列挙しない。16:9 のスライドに合う用紙を選べず、A4 横などに余白付きで印刷される。

## 目的

pptx をドロップするだけで、スライドの寸法どおりの PDF を、空白を保ったまま作れるようにする。

## ユーザー

講義資料を作る本人（1 人）。Windows と PowerPoint がある PC で使う。

## 解決策

1. Microsoft Print to PDF に、スライドより大きい用紙（A3 横）へ 100% で印刷する。用紙の指定は、ユーザーごとの印刷設定（`SetPrinter` Level 9）を印刷の間だけ切り替えて行う。管理者権限は要らない。
2. 印刷した PDF の各ページを、スライドの寸法の矩形（ページ中央）に切り抜く。文字はベクターのまま。

## スコープ外

- pptx 以外の形式（ppt、odp）。
- PowerPoint が無い環境での変換。
- 半透明など描画の再現性の改善（印刷経路の出力をそのまま使う）。
- 出力先の指定（デッキと同じ場所に同名の pdf を書く）。
