# 機能一覧

| # | 機能 | 説明 | 状態 |
|---|---|---|---|
| 1 | ファイルの追加（ドロップ） | ウィンドウに pptx ファイルをドロップすると一覧に入る。pptx 以外と重複は無視する | 実装済み |
| 2 | ファイルの追加（ダイアログ） | 「ファイルを追加...」でファイル選択ダイアログから複数選ぶ | 実装済み |
| 3 | 一括変換 | 「PDFに変換」で待機中の項目を順に変換する。変換中は再実行できない | 実装済み |
| 4 | 進行状況の表示 | 項目ごとに 待機／印刷中／切り抜き中／完了／失敗 を表示する | 実装済み |
| 5 | 失敗の表示 | 変換に失敗した項目は失敗と理由を表示し、次の項目に進む | 実装済み |
| 6 | 一覧の整理 | 「完了した項目を一覧から外す」で完了と失敗の項目を一覧から外す。pptx も PDF も削除しない | 実装済み |
| 7 | 出力先 | デッキと同じフォルダーに同名の pdf を書く。既存のファイルは上書きする | 実装済み |
| 8 | 予期しないエラーの表示 | バグ由来の例外はスタックトレース付きのダイアログに出す | 実装済み |
